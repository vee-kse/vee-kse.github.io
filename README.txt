DEPLOY
1. Unzip. Put every file in the root of your vee-kse.github.io repo.
2. Commit and push. GitHub Pages serves index.html at https://vee-kse.github.io/

NEW POST
1. Copy posts/example-post.html and rename it (my-post.html).
2. Edit the title, description, date and body.
3. Copy the <li> block in index.html, change the link, title, summary, date and data-tags.
   Tag values: metrics, ai-risk, ux. Add a new tag by adding a button in index.html.
